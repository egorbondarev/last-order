# Мастерская «Последнего заказа»

Здесь лежат карты для **Deathmatch**, которые видит встроенная мастерская
веб-версии игры. Сервера у игры нет — мастерская живёт прямо в этом репозитории.

```
workshop/
  index.json        список карт (одним файлом) — его читает игра
  maps/*.json       сами карты: по файлу на карту
  build_index.py    сборка index.json из maps/
```

## Что видит игра

Игра запрашивает `workshop/index.json` по адресу Pages
(`https://egorbondarev.github.io/last-order/workshop/index.json`), а если его
нет — пробует `raw.githubusercontent.com`. Экран **Мастерская → Мастерская · GitHub**
показывает список: любую карту можно сразу играть или утащить в «Мои карты»,
после чего она играется без сети.

Внутри `index.json` лежат не только подписи, но и сами карты, поэтому игра
обходится одним запросом и умеет работать офлайн после установки карты.

## Как опубликовать карту

Собрал арену в редакторе (**Меню → Мастерская → Создать карту**, либо
**Deathmatch → Редактор карт**) — дальше два пути.

**1. Без репозитория — ссылкой.** «Поделиться» даёт ссылку вида
`…/last-order/#map=<код>`: она открывает карту у любого, у кого есть игра,
без всякой публикации. Годится для друзей и для чата.

**2. В общую мастерскую — файлом.** «Отправить в GitHub» открывает страницу
нового файла с уже вписанным содержимым: остаётся нажать **Commit changes**.
Файл должен попасть в `workshop/maps/<slug>.json`.

После этого список пересобирается сам: воркфлоу
`.github/workflows/workshop-index.yml` запускает `build_index.py` на каждый
пуш в `workshop/maps/**` и коммитит обновлённый `index.json`.

Если правишь карты руками (или в веб-интерфейсе GitHub), пересобери список
локально и запушь оба файла:

```bash
python workshop/build_index.py
git add workshop/index.json workshop/maps
git commit -m "Мастерская: новая карта"
git push
```

## Формат карты

```jsonc
{
  "v": 1, "kind": "dm-map",
  "id": "zavodskoy-dvor-678e",     // уникальный id (по нему обновляется карта)
  "slug": "zavodskoy-dvor",        // имя файла: workshop/maps/<slug>.json
  "title": "Заводской двор",
  "author": "Марк",
  "theme": "concrete",             // asphalt | concrete | dirt | grass | sand
  "created": "2026-11-27",
  "start":  { "x": 500, "y": 470 },          // где появляется игрок
  "spawns": [ { "x": 160, "y": 110 } ],      // точки боя ботов (нужно ≥ 4)
  "ammoSpots": [ { "x": 340, "y": 200 } ],   // склады под снабжение (≥ 6)
  "props": [
    { "type": "crate", "x": 430, "y": 200, "w": 42, "h": 42, "rot": 0, "solid": true }
  ],
  "objects": [ { "kind": "tank", "x": 770, "y": 170, "rot": 1 } ],
  "pads":    [ { "x": 570, "y": 420 }, { "x": 570, "y": 250 } ]
}
```

* `props[].solid` — **физика**: `true` мешает пройти (как доски у моста),
  `false` — просто текстура на полу.
* `props[].rot` — разворот в четвертях оборота (`0..3`). Для лестницы меняет
  направление ступеней, для прямоугольников в редакторе меняет местами стороны.
* `objects[].kind` — `"tank"` или `"mortar"`. `rot` задаёт, куда смотрит ствол.
* `pads` — площадки лестничного перехода, связываются **попарно**:
  первая со второй, третья с четвёртой. Встал на одну — оказался на второй.

Типы укрытий и текстур: `crate`, `sandbag`, `block`, `barrier`, `car`, `wall`,
`water`, `stair`, `tex_boards`, `tex_rubble`, `tex_grass`, `tex_puddle`,
`tex_tiles`, `tex_stain`.

Карту можно проверить, не открывая игру: любой файл из `maps/` годится как
описание уровня, а «починку» (мало точек боя, старт в укрытии, непарная
площадка) игра делает сама при сохранении и сообщает об этом в редакторе.
